# GG Motion style library

Curated, render-verified building blocks for Motion videos, used through
`bin/library.mjs`. Two kinds of entry:

- **Looks** (`looks/<id>/`): a complete art direction — palette, type,
  background treatment, framing, motion rhythm. One per video.
- **Pieces** (`pieces/<id>/`): a seek-safe building block (background, type
  move, diagram, UI, frame, transition, texture) that reads its colors and
  fonts from whichever look the video uses.

`library.json`, every `preview.jpg`, and `sheets/*.jpg` are generated by
`scripts/build-motion-library.mjs`. Never edit them by hand; re-run the
script after changing an entry. It lints and renders every entry with the
bundled HyperFrames and fails on any rule below.

## Tokens (the look ↔ piece contract)

Every look's `tokens.css` defines all of these on `.look-<id>`; every piece
reads only these (plus its own literal geometry):

| Token | Meaning |
|---|---|
| `--field` | Main background color |
| `--field-2` | Alternate field for scene changes (color-field cuts) |
| `--ink` | Primary type and line color; at least 4.5:1 on `--field` (aim for 7:1 on light and dark fields) |
| `--accent` | The one emphasis color (may equal `--ink` in two-color looks) |
| `--muted` | Secondary text / annotations; must reach 4.5:1 on `--field` (it is used for small labels) |
| `--line` | Hairlines, grids, dots |
| `--display` | Headline font stack |
| `--display-weight` / `--display-stretch` / `--display-tracking` | Headline cut |
| `--text` | Supporting text font stack |
| `--mono` | Labels, readouts, code |
| `--radius` | Corner radius for cards and UI |

Pieces may set local fallbacks (`var(--ink, #111)`) but must not hardcode
brand colors or font names.

## Piece rules

`pieces/<id>/piece.html` is a full HTML document, like a HyperFrames catalog
block:

- Root: `<div id="<id>-root" data-composition-id="<id>" data-start="0"
  data-duration="<s>" data-width="1920" data-height="1080">`.
- Styles scoped under `[data-composition-id="<id>"]`. In scripts, find the
  root with `document.querySelector('[data-composition-id="<id>"]')`, never
  `getElementById("<id>-root")`: HyperFrames drops that id when it mounts
  the piece. For generated grid/flex children, query an explicit inner
  container before inserting them. Do not append layout children directly
  to the mount: the authored root styles may belong to its inner wrapper.
- Timeline: `gsap.timeline({ paused: true })` registered as
  `window.__timelines["<id>"]`. GSAP from
  `https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js` (the same pin
  HyperFrames' catalog uses) — the only remote URL allowed.
- Seek-safe: every visual is a pure function of timeline time. No
  `Math.random` (seeded generators only), `Date.now`, `performance.now`,
  `requestAnimationFrame`, timers, or `infinite` CSS animations.
- WebGL / canvas pieces draw from a tween's `onUpdate` on the piece's own
  timeline (local time), never from the global `hf-seek` event.
- 3D pieces set `"requires": ["three"]` in meta.json and import `three` /
  `three/addons/...` in a `<script type="module">`. The bundled Three.js
  and its importmap are installed into the project by `library.mjs add`
  (the importmap goes in the root `index.html` head).
- Editable copy is plain text in the markup, marked with
  `<!-- edit: ... -->` comments; parameters are CSS variables or constants
  at the top of the script, documented in a header comment.
- No remote fonts, images or scripts besides GSAP. Fonts come from the look.

`meta.json`:

```json
{
  "id": "slam-word",
  "name": "Slam word",
  "kind": "type",
  "description": "One huge word rises from a mask and widens as it lands.",
  "tags": ["kinetic", "headline", "variable-font"],
  "fonts": [],
  "duration": 3,
  "previewAt": 1.4,
  "license": "original",
  "previewLook": "duotone-broadcast"
}
```

`kind` is one of: background, type, diagram, data, ui, frame, transition,
texture. `license` is `"original"` or `"MIT"`; MIT pieces also need
`"source": { "url": "...", "author": "..." }` and are credited in the
project's `CREDITS.md` when added.

## Look rules

`looks/<id>/` contains:

- `meta.json`: id, name, description, tags, fonts (bundled family names),
  bestFor, pieces (ids that suit it), samplePieces (mounted by the sample),
  previewAt.
- `tokens.css`: every token, scoped to `.look-<id>`.
- `look.md`: the art direction — palette logic, type rules, background and
  framing, motion rhythm (eases, holds, transitions), what to avoid, and
  2–3 scene recipes.
- `sample.html`: a one-scene composition that shows the look, used for its
  preview. It links `assets/fonts/fonts.css` and `assets/looks/<id>.css`.
  Videos should instead paste the `head` that `library.mjs look` returns: it
  declares the fonts in the page, which `hf check` requires.
